# Barber Bot

Телеграм-бот для барбершопу українською мовою. Клієнт може переглянути послуги й ціни та дізнатися контакти. Запис на стрижку додається.

## Технології

Node.js, grammY, dotenv

## Як запустити

1. Встановіть Node.js
2. Скопіюйте проєкт і виконайте `npm install`
3. Створіть файл `.env` за зразком `.env.example` і вставте свій токен
4. Запустіть `node index.js`

## Структура проєкту

- `index.js` - точка входу
- `src/config.js` - налаштування бізнесу (послуги, години роботи)
- `src/storage.js` - збереження заявок
- `src/handlers/` - обробники: меню і запис
- `src/handlers/myBookings.js` - перегляд і скасування записів клієнтом
- `src/handlers/admin.js` - команди майстра: /today, /tomorrow


## Можливості

- Запис на послугу з вибором дати й часу, зайняті години приховуються
- Валідація українських номерів телефону
- Сповіщення майстру про нові й скасовані записи
- «Мої записи»: перегляд і скасування (не пізніше ніж за 2 години до візиту)
- Команди майстра /today і /tomorrow зі списком записів і сумою
