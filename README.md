# Barber Bot

Телеграм-бот для барбершопу українською мовою. Клієнт може переглянути послуги й ціни та дізнатися контакти. Запис на стрижку додається.

## Технології

Node.js, grammY, dotenv

## Як запустити

1. Встановіть Node.js
2. Скопіюйте проєкт і виконайте `npm install`
3. Створіть файл `.env` за зразком `.env.example` і вставте свій токен
4. Запустіть `node index.js`

## Структура проєкту

- `index.js` - точка входу
- `src/config.js` - налаштування бізнесу (послуги, години роботи)
- `src/storage.js` - збереження заявок
- `src/handlers/` - обробники: меню і запис
